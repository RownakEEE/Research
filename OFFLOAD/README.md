# OFFLOAD: Heterogeneous Computing & Task Offloading Framework

**OFFLOAD** is an open-source, hardware-agnostic framework for distributing AI and data-intensive tasks across heterogeneous computing platforms. The framework bridges high-level software environments with diverse compute units through a unified task-offloading and hardware–software interface. The system integrates **data processing, task partitioning, shared-memory communication, and custom firmware** within a controller–worker architecture. A hardware prototype demonstrates end-to-end execution from database queries to distributed processing across heterogeneous embedded computing devices.

---

## Research Highlights

- **Heterogeneous Computing** — Distribution of workloads across different compute platforms using a unified framework.
- **Hardware–Software Co-design** — Multi-level integration spanning applications, data frameworks, firmware, memory, and hardware.
- **Task Offloading** — Controller–worker architecture for partitioning and distributing computation across worker nodes.
- **Shared-Memory Communication** — Memory-mapped task and data exchange between controller and heterogeneous workers.
- **Data Processing Pipeline** — Integration of database queries with Apache Spark, Apache Arrow, and Parquet-based data organization.
- **Hardware Prototyping** — End-to-end implementation using Raspberry Pi and NVIDIA Jetson Nano platforms.
