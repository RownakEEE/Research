# FPGA ECC Crypto Engine

**FPGA ECC Crypto Engine** explores hardware acceleration techniques for Elliptic Curve Cryptography (ECC), focusing on efficient modular arithmetic and elliptic-curve point operations. The work targets **256-bit prime-field arithmetic** and FPGA-based implementations for improving the performance and hardware efficiency of cryptographic computation. The research spans **modular arithmetic architectures, Booth-based multiplication, modular reduction, unified point operations, and FPGA implementation of Twisted Edwards Curve Cryptography**.

---

## Research Highlights

- **Modular Arithmetic** — Hardware architectures for 256-bit modular addition, subtraction, multiplication, and reduction.
- **Booth-Based Multiplication** — Radix-4 Booth multiplication combined with fast modular reduction for efficient prime-field arithmetic.
- **Unified Point Operations** — Hardware architecture supporting both elliptic-curve point addition and point doubling using a unified computational structure.
- **Twisted Edwards ECC** — FPGA implementation of point operations for Twisted Edwards Curve Cryptography.
- **Hardware Optimization** — Evaluation of FPGA resource utilization, latency, operating frequency, and computational performance.
